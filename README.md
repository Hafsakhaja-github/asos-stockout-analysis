# ASOS Stockout Analysis

## Overview
This project analyzes ASOS product inventory data to identify brands suffering from stockouts and estimate potential lost revenue.

## Objectives
- Extract brand information from product descriptions
- Calculate stockout rates
- Estimate lost revenue from unavailable sizes
- Identify high-priority brands for inventory investment

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Insights
- Calculated stockout rates at the product and brand level
- Estimated revenue loss from unavailable inventory
- Visualized brands with high prices and high stockout rates
- Identified brands requiring immediate inventory attention

## Visualization

The scatter plot highlights:
- X-axis: Average Price
- Y-axis: Stockout Rate
- Bubble Size: Lost Revenue

Brands in the upper-right quadrant represent premium brands with significant inventory issues.
